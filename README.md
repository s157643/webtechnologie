# webtechnologie
Assignment for a school portfolio website.
Als je website lokaal wel werkt, dan is je code technisch in orde en ligt het probleem puur bij de limieten van Netlify (zoals de melding in je screenshot al aangaf).
Omdat je lokaal geen data-limiet hebt, merk je daar niets van, maar zodra je de site online zet, blokkeert Netlify de toegang omdat je over hun gratis 100GB heen bent.
Hoe los je dit nu op?
Je hebt drie snelle opties om je site weer online te krijgen zonder te betalen:
1.	Gebruik Vercel (Aanrader):
Ga naar Vercel.com, log in met je GitHub-account en importeer je repository. Vercel is een direct alternatief voor Netlify, werkt bijna hetzelfde en je site krijgt direct een nieuwe, werkende link.
2.	Maak een nieuw Netlify-account:
Je kunt een nieuw account aanmaken met een ander e-mailadres en je code daar opnieuw uploaden. Je krijgt dan weer een verse 100GB.
3.	Activeer GitHub Pages:
Omdat je code al op GitHub staat, kun je gratis hosting van GitHub zelf gebruiken:
o	Ga naar je repository op GitHub.
o	Klik op Settings > Pages.
o	Kies bij 'Branch' de main branch en klik op Save.
o	Na een paar minuten is je site online op jouwgebruikersnaam.github.io/projectnaam.
Belangrijke tip om dit te voorkomen:
De reden dat je zo snel door je 100GB heen bent, is waarschijnlijk die profile-img.jpg. Als die foto bijvoorbeeld 5MB of 10MB groot is, verbruik je bij elke keer dat je de site bekijkt enorm veel data.
•	Oplossing: Verklein de foto naar ongeveer 200KB met een tool zoals TinyPNG voordat je hem opnieuw uploadt naar je nieuwe host.
